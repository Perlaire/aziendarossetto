📤 Esporta Dati

Scarica tutti i dati dell'app come file sul tuo dispositivo. Mandalo sull'altro dispositivo e importalo per avere gli stessi dati ovunque.

📥 Importa Dati

Carica un file di backup esportato in precedenza. Attenzione: i dati attuali verranno sostituiti con quelli del file.

📋 Come sincronizzare telefono e computer

1️⃣ Sul dispositivo con i dati aggiornati → clicca Esporta
2️⃣ Si scarica un file rossetto-backup.json
3️⃣ Mandalo all'altro dispositivo via WhatsApp, email, USB...
4️⃣ Sull'altro dispositivo → clicca Importa e scegli il file ✅
